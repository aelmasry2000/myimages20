ScriptShifter for Alma Metadata Editor

Click a text field in Alma, then capture it here. This panel stays open while you switch fields.

Saved corrections stay in this browser and contain the source and corrected text. Review each result before insertion. Original-script input: keep it below and put romanization above. Romanized input: keep it above and put original script below. Uses Alma’s Ctrl+L action; review the selected direction and conversion first. For fields other than 245, create the alternate row in Alma, click its empty text control, then use Insert conversion into current field. Conversion sends text to bibframe.org; Alma credentials are never sent.
