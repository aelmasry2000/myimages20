# Extension downloads

- [FOLIO ZIP](https://github.com/aelmasry2000/myimages20/raw/refs/heads/main/downloads/folio-scriptshifter.zip)
- [Alma Metadata Editor ZIP](https://github.com/aelmasry2000/myimages20/raw/refs/heads/main/downloads/alma-metadata-scriptshifter.zip)
- [Alma BIBFRAME Editor ZIP](https://github.com/aelmasry2000/myimages20/raw/refs/heads/main/downloads/alma-bibframe-scriptshifter.zip)

These are separate extensions, each fixed to its own editor mode. Unzip the desired archive, enable Developer mode in `chrome://extensions` (or `edge://extensions`), then Load unpacked from its extracted extension folder. Disable/remove the older combined Alma prototype first.

Both are prototypes. Automatic native parallel-field/property creation and live Alma persistence are not verified or implemented; see each included README for the exact scope. Copyright © 2026 Ayman El-Masry.
